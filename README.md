## 🧐 About the Project

**FitLog** simplifies workout planning by providing a clean, distraction-free interface to manage your exercise routine. Users can browse through a curated collection of exercises categorized by muscle groups, view key metrics (estimated duration, calorie burn, rating, and required equipment), and assemble a customized workout plan.

---

## 🛠️ Tech Stack

- **Framework:** Next.js / React
- **Styling:** Tailwind CSS / CSS Modules
- **Deployment:** Vercel
- **Language:** JavaScript (ES6+) / HTML5

---

## ✨ Features

1. 🏋️ **Comprehensive Exercise Library:** Browse through a structured list of lifts and exercises targeting major muscle groups (Chest, Back, Legs, Shoulders, Core, and Arms).
2. 🎯 **Workout Details & Metrics:** View important details for each exercise, including required equipment, estimated duration, estimated calorie burn, and user ratings.
3. 📋 **Custom Workout Planner ("My Plan"):** Easily lock selected exercises into your personal daily schedule to build tailored workout sessions.
4. 🔢 **Dynamic Plan Tracker:** Real-time badge and tracker indicating the total number of workouts currently added to your personal routine.
5. 📱 **Responsive & Dark-Mode Design:** Built with a sleek, dark aesthetic optimized for smooth navigation across mobile, tablet, and desktop devices.
